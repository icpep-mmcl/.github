This is the special `.github` repository for **ICpEP-MMCL**.

GitHub treats this repository differently from the others. Anything placed here is shared across the whole organization.

## What's inside

```
.github/
├── profile/
│   └── README.md    # The welcome page shown on our organization's GitHub profile
└── README.md        # This file, which explains the repository
```

### `profile/README.md`

This file is what visitors see when they open our organization's page on GitHub. It's the "front page" of ICPEP-MMCL, so keep it short, friendly, and up to date. Editing it changes what the public sees.

## How to update the organization page

1. Open the `profile` folder and click `README.md`.
2. Click the pencil icon to edit.
3. Make your changes, then click **Commit changes**.
4. Refresh our organization page. The update shows up within a minute or two.

## Rules for editing

- Only officers with access should edit these files.
- This repository is **public**, so never add personal details of members, such as emails, phone numbers, or ID photos.
- Keep the tone welcoming. This is the first thing newcomers see.

## About ICPEP-MMCL

ICPEP-MMCL is a student chapter of the regional student organization ICpEP.se R4A. We organize events, seminars, technical workshops, competitions, and hackathons for our members.
